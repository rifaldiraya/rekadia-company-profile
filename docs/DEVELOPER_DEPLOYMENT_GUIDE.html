Developer Deployment Guide

Step-by-step deploy RKD Next.js Template ke Linux (offline / online) atau Windows IIS.

Node.js 20/22 LTS · Next.js · Nginx · IIS + iisnode

Linux Offline (Ubuntu)

Preparation di laptop Windows (online) → deploy ke server Ubuntu tanpa internet.

Ringkasan arsitektur

Browser  →  Nginx (:80/:443)  →  Node.js (next start :3000)
                                      ↓
                               Backend API (LAN / internal)

Aplikasi ini bukan static site. Nginx hanya reverse proxy; proses Node harus tetap berjalan.

Laptop Windows (ada internet)          Server Ubuntu (offline)
  1. Set env & build                     4. Install Node + Nginx dari file lokal
  2. Download Node Linux + Nginx .deb    5. Copy app → jalankan next start
  3. Pack ke USB / media                 6. Nginx reverse proxy ke :3000

Prerequisites

ItemKeterangan
Laptop WindowsAda internet; Node.js 20.x / 22.x untuk build
Server UbuntuOffline; catat versi (20.04 / 22.04 / 24.04)
Media transferUSB, harddisk, atau share LAN
Backend APIReachable dari browser user di LAN

Fase 1 — Preparation di laptop Windows

1. Siapkan environment produksi

Edit .env.production (atau .env.staging) sebelum build:

BASE_URL=http://IP-API-INTERNAL/services/api/v1
NEXT_PUBLIC_BASE_URL=http://IP-API-INTERNAL/services/api/v1
NEXTAUTH_URL=http://IP-SERVER-UBUNTU
NEXTAUTH_SECRET=<secret-kuat>
JWT_SECRET=<secret-kuat>
  • NEXTAUTH_URL = URL yang dibuka user di browser.
  • NEXT_PUBLIC_* di-bake saat build — ubah nilai → wajib rebuild.
  • Jangan pakai http://localhost:3000 untuk NEXTAUTH_URL di produksi.
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

2. Install dependency & build

npm install
npm run build:prod
CommandEnv source → .env.local
npm run build:dev.env.development
npm run build:staging.env.staging
npm run build:prod.env.production

3–8. Pack aplikasi, runtime & transfer

Struktur contoh D:\deploy-rkd-app\:

D:\deploy-rkd-app\
├── app\                 # aplikasi setelah build
├── runtime\             # Node.js Linux tarball (+ opsional pm2)
└── nginx-debs\          # paket .deb Nginx

Yang wajib di app\: .next, node_modules, public, package.json, next.config.*, .env.local.

robocopy "E:\path\ke\RKD.TEMPLATE.2026.APP" "D:\deploy-rkd-app\app" /E /XD .git

Unduh node-v22.x.x-linux-x64.tar.xz dari nodejs.org/dist ke runtime\. Jangan bawa .msi Windows.

Nginx .deb (versi OS harus cocok) — dari Ubuntu online:

mkdir nginx-debs && cd nginx-debs
sudo apt-get update
apt-get download nginx nginx-common nginx-core

Opsional: npm pack pm2 → taruh di runtime\. Zip seluruh folder ke USB.

Fase 2 — Deploy di server Ubuntu (offline)

9–12. Copy, install Node & Nginx, letakkan app

sudo mkdir -p /opt/deploy-rkd-app
sudo cp -a /media/usb/deploy-rkd-app/. /opt/deploy-rkd-app/

cd /opt/deploy-rkd-app/runtime
sudo tar -xJf node-v22.*-linux-x64.tar.xz -C /usr/local --strip-components=1
node -v && npm -v

cd /opt/deploy-rkd-app/nginx-debs
sudo dpkg -i *.deb
nginx -v

sudo mkdir -p /var/www/rkd-app
sudo cp -a /opt/deploy-rkd-app/app/. /var/www/rkd-app/

13. Jalankan Next.js (systemd)

Tes: cd /var/www/rkd-app && npm run start. Lalu buat /etc/systemd/system/rkd-app.service:

[Unit]
Description=RKD Next.js App
After=network.target

[Service]
Type=simple
WorkingDirectory=/var/www/rkd-app
ExecStart=/usr/local/bin/npm run start
Restart=on-failure
Environment=NODE_ENV=production
Environment=PORT=3000

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now rkd-app

Alternatif PM2: install dari pm2-*.tgz lokal, lalu pm2 start npm --name rkd-app -- start.

14. Nginx reverse proxy

Buat /etc/nginx/sites-available/rkd-app:

server {
    listen 80;
    server_name _;
    client_max_body_size 50M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
sudo ln -sf /etc/nginx/sites-available/rkd-app /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
sudo ufw allow 80/tcp

15. Verifikasi & redeploy

curl -I http://127.0.0.1:3000
curl -I http://127.0.0.1/

Redeploy: rebuild di Windows → ganti app\ → di Ubuntu stop service, copy, start lagi.

Kesalahan yang sering terjadi

SalahBenar
Node Windows (.msi) ke Ubuntunode-*-linux-x64.tar.xz
Copy tanpa .next / node_modulesBawa artifact build lengkap
Nginx serve folder sebagai staticProxy ke 127.0.0.1:3000
NEXTAUTH_URL=localhostIP/hostname yang diakses user

Linux Online (Ubuntu)

Server Ubuntu berinternet. Install Node & Nginx via apt; build di server atau upload artifact.

Ringkasan arsitektur

Browser  →  Nginx (:80/:443)  →  Node.js (next start :3000)
                                      ↓
                               Backend API
1. Install Node + Nginx (apt)
2. Clone / copy source (atau upload artifact)
3. npm install + build:prod
4. systemd / PM2 + Nginx proxy

Prerequisites

ItemKeterangan
Ubuntu20.04 / 22.04 / 24.04 dengan internet
SSHUser dengan sudo
Domain / IPUntuk NEXTAUTH_URL
Backend APIReachable dari browser user

1–2. Install Nginx & Node.js

sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx curl

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v && npm -v

# opsional
sudo npm install -g pm2

3. Siapkan environment

BASE_URL=https://api.example.com/services/api/v1
NEXT_PUBLIC_BASE_URL=https://api.example.com/services/api/v1
NEXTAUTH_URL=https://app.example.com
NEXTAUTH_SECRET=<secret-kuat>
JWT_SECRET=<secret-kuat>

4. Build di server atau upload artifact

Opsi A — Build di server

sudo mkdir -p /var/www/rkd-app
sudo chown -R $USER:$USER /var/www/rkd-app
cd /var/www/rkd-app
git clone <repository-url> .
npm install
npm run build:prod

Opsi B — Build di laptop/CI, lalu rsync

# di mesin build
npm install && npm run build:prod
rsync -avz --exclude .git ./ user@SERVER:/var/www/rkd-app/

# di server (jika perlu)
cd /var/www/rkd-app && npm ci --omit=dev

5. Jalankan dengan systemd atau PM2

/etc/systemd/system/rkd-app.service:

[Unit]
Description=RKD Next.js App
After=network.target

[Service]
Type=simple
WorkingDirectory=/var/www/rkd-app
ExecStart=/usr/bin/npm run start
Restart=on-failure
Environment=NODE_ENV=production
Environment=PORT=3000

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now rkd-app

Atau: pm2 start npm --name rkd-app -- start → pm2 save → pm2 startup systemd.

6. Nginx reverse proxy

Sama seperti tab Offline — proxy / ke http://127.0.0.1:3000, lalu:

sudo ln -sf /etc/nginx/sites-available/rkd-app /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo ufw allow 'Nginx Full'

7. HTTPS (opsional — Certbot)

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d app.example.com

Setelah HTTPS, set NEXTAUTH_URL=https://... dan rebuild jika URL berubah.

8. Verifikasi & redeploy

curl -I http://127.0.0.1:3000
curl -I https://app.example.com/
cd /var/www/rkd-app
git pull          # atau rsync
npm install
npm run build:prod
sudo systemctl restart rkd-app

Windows IIS

Deploy memakai iisnode, custom server.js, dan web.config di root repo.

Ringkasan arsitektur

Browser  →  IIS (URL Rewrite)  →  iisnode  →  server.js (Next.js)
                                                      ↓
                                               Backend API

Referensi CI: azure-pipeline-dev.yml, azure-pipeline-staging.yml, azure-pipeline-prod.yml.

Prerequisites

ItemKeterangan
Windows ServerIIS (Web Server role)
Node.js WindowsLTS 20/22 — path cocok dengan web.config
iisnodeModul IIS untuk Node
URL RewriteRewrite request ke server.js

1. Install komponen di server

  1. Install Node.js Windows LTS dari nodejs.org
  2. Install IIS (Server Manager → Web Server)
  3. Install URL Rewrite Module (Microsoft)
  4. Install iisnode (x64)
node -v
where node

2. Environment & build

Edit .env.production / .env.staging sebelum build:

BASE_URL=https://api.example.com/services/api/v1
NEXT_PUBLIC_BASE_URL=https://api.example.com/services/api/v1
NEXTAUTH_URL=https://app.example.com
NEXTAUTH_SECRET=<secret-kuat>
JWT_SECRET=<secret-kuat>
npm install
npm run build:prod
# atau: npm run build:staging

3. Sesuaikan web.config

  1. appSettings — NEXTAUTH_URL & NEXTAUTH_SECRET harus cocok dengan host frontend.
  2. nodeProcessCommandLine — path node.exe di server, contoh:
    C:\Program Files\nodejs\node.exe
  3. Rewrite rule mengarahkan request ke server.js (kecuali path yang di-negate, mis. /services).

Jangan commit secret produksi ke Git; sesuaikan nilai di server / pipeline.

4. Buat Site & Application Pool

  1. IIS Manager → Application Pools → Add: .NET CLR = No Managed Code
  2. Sites → Add Website: physical path = folder deploy, binding HTTP/HTTPS, pilih App Pool baru

5. Deploy file ke physical path

PathKeterangan
.next\Hasil build
node_modules\Runtime deps
public\Static assets
package.jsonScripts / deps
server.jsEntry iisnode
web.configIIS + iisnode
next.config.*Config Next

App Pool identity butuh Read/Execute. Folder iisnode harus writable untuk log.

6. Recycle & uji

Import-Module WebAdministration
Restart-WebAppPool -Name "RKD.APP"

Buka URL binding → uji login NextAuth dan API.

Pipeline contoh: npm install → build:staging → recycle App Pool → deploy package ke IIS site.

7. Troubleshooting

GejalaCek
500.19URL Rewrite / iisnode belum terpasang
500.1001 / iisnodeLog iisnode\; path node.exe
Blank / 502server.js gagal start; permission
NextAuth redirect salahNEXTAUTH_URL ≠ URL browser
API gagalNEXT_PUBLIC_BASE_URL / perlu rebuild

8. Redeploy

  1. Build ulang (build:prod / build:staging)
  2. Overwrite file di physical path (minimal .next)
  3. Recycle Application Pool
